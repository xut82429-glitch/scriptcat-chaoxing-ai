# 超星学习通满分助手（已添加 Agnes AI 支持）

## 文件说明

- **💯【超星学习通满分助手】支持 LLM 智能答题.user.js** - 这是你需要导入 ScriptCat 的唯一文件

## 如何导入 ScriptCat

1. 打开 ScriptCat 扩展管理页面
2. 点击"导入脚本"或"+"按钮
3. 选择文件：`💯【超星学习通满分助手】支持 LLM 智能答题.user.js`
4. 确认导入

## 配置 Agnes AI

导入后，在脚本设置中：
1. 打开"LLM 配置"选项卡
2. 在"LLM 提供商"下拉框中选择 **Agnes AI**
3. 填写你的 API Key（获取地址：https://apihub.agnes-ai.com/console/api-keys）
4. 保存配置

## 注意事项

- 只需导入 `.user.js` 结尾的文件，其他都是依赖库文件
- 不要导入整个文件夹
- Agnes AI 模型使用 `agnes-3.0-flash`，上下文窗口 512K
